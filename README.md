# 🧠 BrainQuest

Интерактивная викторина для детей с красивым UI, тёмной/светлой темой, анимациями и экспортом результатов.

## ✨ Возможности

- 🎯 **10 вопросов** для детей 9–11 лет
- 🔬 **15 вопросов** для детей 12–14 лет
- 🌙 **Тёмная/светлая тема** с плавным переключением
- 🎉 **Анимации и конфетти** за правильные ответы
- 🔥 **Стрик-система** — награды за серию правильных ответов
- 📊 **Подробные пояснения** к каждому ответу
- 💾 **LocalStorage** — сохранение прогресса
- 📥 **Экспорт в Word (.docx) и Excel (.xlsx)**
- 📱 **Адаптивный дизайн** для мобильных устройств

## 🛠 Стек технологий

- **React 18** + React Router DOM
- **CSS Custom Properties** для тем
- **Framer Motion** для анимаций
- **docx** — генерация Word документов
- **xlsx** — генерация Excel таблиц
- **canvas-confetti** — конфетти эффекты
- **Nunito + Fredoka One** — Google Fonts

## 📁 Архитектура проекта

```
src/
├── components/       # Переиспользуемые компоненты
│   ├── ProgressBar.jsx
│   └── ThemeToggle.jsx
├── data/            # Данные и контент
│   └── questions.js
├── hooks/           # Кастомные хуки
│   ├── useLocalStorage.js
│   └── useTheme.js
├── pages/           # Страницы приложения
│   ├── Home.jsx     # Главная — выбор возраста и имени
│   ├── Quiz.jsx     # Прохождение теста
│   └── Result.jsx   # Результаты с экспортом
├── styles/          # Глобальные стили
│   └── globals.css
└── utils/           # Утилиты
    ├── confetti.js
    └── export.js
```
